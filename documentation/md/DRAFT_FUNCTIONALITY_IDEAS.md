# Draft Functionality Ideas

A running list of feature/functionality ideas that haven't been scoped into a real ticket yet.
This is a scratchpad for early-stage thinking — lower ceremony than `PROGRESS.md` (which records
decided/completed work) or a module `BACKLOG_*.md` (which holds actionable tickets). An idea lives
here until someone decides it's worth scoping properly, at which point it graduates into a real
ticket (via `/feature`) in the relevant backlog, and its entry here should be marked `PROMOTED` with
a pointer to that ticket rather than deleted.

## How to use this file

- Add new ideas with `/draftidea` — don't hand-edit this file directly, so every entry goes through
  the duplicate/conflict check against what's already here.
- Entries are numbered `IDEA-<n>`, sequential, never reused even if an idea is dropped.
- Status values: `DRAFT` (just logged, not evaluated) · `PROMOTED` (turned into a real ticket —
  link it) · `REJECTED` (considered and explicitly dropped — say why, so it isn't re-proposed
  blindly later) · `SUPERSEDED` (folded into a later, broader idea — link it).
