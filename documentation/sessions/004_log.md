- **`GROUP_BROADCAST` posting permission:** owner/admin only (not all members)
- **Existing posts deleted** in migration (TRUNCATE posts CASCADE) — dev environment, no data worth preserving
- **`postType` is separate from `visibility`** — orthogonal concerns; not a replacement
- **`post-impl` → `group-api` dependency** for membership checks — no circular dependency since `group-impl` has no dependency on `post-api`
- **Stop hook updated** to track full reasoning journey (analysis + discussion + questions + final decision) in MD files, not just the conclusion — while still requiring a PROGRESS.md summary
