# INFRA-12 · A1 box migration log

The chronological record of the move to the Always Free A1 box (arm64), kept the way `INFRA-3_ORACLE_REBUILD_LOG.md` was kept for the first box: one row per action, with who ran it, the command, and the result. Plan and decisions: `INFRA-12_SPIKE_ORACLE_ALWAYS_FREE_HOSTING.md` (section "Plan for the move"); the procedure itself is `../PRODUCTION_DEPLOYMENT_GUIDE.md`. Rules: nothing marked "success" that was not observed; a step that was not run says "not run"; a result the owner reported without pasting output says "owner's word"; no secret, key, token or password appears here.

Boxes: the reference box is the x86 production box (`sc-box`, `VM.Standard.E3.Flex`, 2 OCPU / 12 GB); the new box is `sc-a1` (Ubuntu 24.04.5, aarch64, Ampere Altra 3.0 GHz, 2 OCPU / 12 GB, 96 GB boot volume, private address in the same `10.0.0.0/24` subnet). The A1 box's public address and instance OCID were given by the owner in chat; the OCID is needed only for the dynamic-group rule at the cutover (step D) and is recorded with the other resource names in `INFRA-3_ORACLE_RESOURCES.md` then.
