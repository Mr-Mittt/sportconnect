# INFRA-12 · Oracle instance setup log

Chronological record (oldest first) of how the INFRA-12 spike instance was created and prepared on 2026-10-26: each step, why, the command or console action, and whether it worked. Findings and the go/no-go live in `INFRA-12_SPIKE_ORACLE_ALWAYS_FREE_HOSTING.md`; this file is only the "what was done".

**Placeholders:** `<ip>` is the instance's public IP and `<key>` the path of the downloaded SSH private key. Neither is committed. The private key never leaves the owner's machine.

**Who did it:** steps marked *console* were done by the repo owner in the Oracle Cloud console. Steps marked *ssh* were run by Claude over SSH, non-interactively, after the owner approved them. All server-side times are UTC.

**Important: this is a credit-funded sandbox, not the Always Free test.** `VM.Standard.A1.Flex` was out of capacity (step 4), so the stack measurements run on a paid AMD shape paid for from the Oracle free-trial credit. Results say how big the stack is and whether Oracle works as a host. They do **not** prove the Always Free allowance fits, and points 1, 2, 3 and 5 of INFRA-12 stay open.
