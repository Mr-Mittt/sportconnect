Notes

• All five sections open by default, one scroll, one submit; no wizard.
• The amber chip is information, not an error (text carries the meaning). Red asterisk stays for what is needed to create: sport, start, open slot.
• "(optional)" is gone from every label; unmarked means optional. Title and duration are optional now.
• The old footer line "will be created as Preparing" is gone: clicking Create opens the readiness popup (C2/C3).
• Game mood always has a value (default 5); an untouched slider counts as the answer. The number sits beside the slider, colour is only an accent.
• Who can join: Anyone (default) or By gender, radios stacked in a column. By gender unlocks two checkboxes, Male slot and Female slot, each with its own two-digit number input (smaller than Open slot); a ticked box with a number reserves that many of the open slots, and male + female over the open slots shows a red line. Switching back to Anyone clears both.
• Session detail (the sport's session attributes) stays, as the last section, only for a sport that has a session schema. Description is gone from the form.
• Overview holds only sport and title for now (sport is fixed after creation, so only the title is editable in the detail).

Notes

• Sections are collapsible. Collapsed, a section shows its fields as field: value, in a wrapping row; a missing value reads ... (amber).
• The Edit button sits in the section header and only exists on a PREPARING session, for the host. Clicking it also expands the section.
• In edit mode the same spot shows Discard and Save (icon only at 375px). Save sends only that section's fields; Discard drops the draft.
• Expanding a section scrolls the modal body just enough that the whole section is visible (nearest-edge scroll); a section taller than the modal aligns its top.
• Expanded sections let the host set a missing value and change an existing one, as long as the session is PREPARING.
• The other Edit buttons are disabled while one section is editing (D2).
• Mark it scheduled is the footer button (disabled until nothing is missing). It opens popup C3; "Let's go" calls POST /schedule. When the host saves the last missing field, C3 opens by itself.
